프리셋 저장하기

프리셋은 지금 화면 입력칸에 있는 내용을 이름을 붙여 저장해 두는 기능입니다. (학생 목록, 단어, 항목 등 — 도구마다 다름)

  1. 저장할 내용을 입력칸에 넣습니다.
  2. 프리셋 이름을 적습니다. 반·수업 이름처럼 알아보기 쉬운 이름이 좋습니다.예: DSA1, 3학년 2반
  3. 저장 또는 새로 저장을 누릅니다.

같은 이름으로 다시 저장하면 덮어쓸지 물어볼 수 있습니다.

프리셋 불러오기

  1. 저장된 목록에서 이름을 고릅니다.
  2. 불러오기를 누르면 입력칸 내용이 그때 저장했던 상태로 바뀝니다.

참고

  • 목록을 고친 뒤에는 현재 프리셋 업데이트로 다시 저장할 수 있습니다. (학생 목록 도구)
  • 더 이상 쓰지 않는 프리셋은 선택 후 삭제할 수 있습니다.
  • 저장된 프리셋은 이 컴퓨터·이 브라우저에만 남습니다.
  • Random Picker, Team Maker, Participation Tracker, Vocab Study Tool, Dice Tool 등 일부 도구에서 사용할 수 있습니다.

수업준비 체크리스트

소개

교시별 수업 준비물을 체크하는 도구입니다.

사용 방법

  • ← / → 버튼으로 반 또는 교시를 이동합니다.
  • 필요한 준비물을 체크합니다.
  • 반 설정에서 반 이름을 수정할 수 있습니다.
  • 항목 설정에서 체크리스트 항목을 수정할 수 있습니다.

주의사항

반 설정과 항목 설정은 저장 버튼을 눌러야 반영됩니다. 반마다 체크 항목은 따로 저장됩니다.

오늘 보강 위젯

소개

오늘 예정된 보강 일정을 메인 화면에서 확인하는 위젯입니다. 보강 관리 캘린더(Supabase)와 연동됩니다.

사용 방법

  • 메인 화면에서 오늘 보강 일정을 확인합니다.
  • ← / → 버튼으로 보강 일정을 넘겨볼 수 있습니다.
  • 일정은 자동으로 전환됩니다.
  • 보강 등록·수정은 보강 관리 열기 또는 카드 클릭으로 보강 캘린더에서 진행합니다.

주의사항

같은 브라우저에서 보강 캘린더에 Google 로그인해 두면 위젯에도 오늘 일정이 표시됩니다. 로그인하지 않았으면 로그인 안내가 나옵니다. 위젯에서는 일정을 직접 수정할 수 없습니다.

Classroom Timer

소개

수업 활동 시간을 관리하는 타이머입니다.

사용 방법

  • 숫자를 입력합니다.
  • Start를 눌러 타이머를 시작합니다.
  • Pause로 일시정지할 수 있습니다.
  • Reset으로 초기화할 수 있습니다.

입력 방법

숫자 버튼 또는 키보드 숫자를 사용할 수 있습니다. 예를 들어 630을 입력하면 6분 30초로 설정됩니다.

단축키

  • Enter: 시작 또는 재개
  • Space: 시작, 일시정지, 재개
  • Backspace: 한 자리 삭제
  • C: Clear
  • R: Reset
  • F: 전체화면
  • Esc: 닫기 또는 취소

주의사항

실행 중에는 숫자 입력과 Clear가 비활성화됩니다.

Makeup Scheduler

소개

결석한 학생의 보강 일정을 등록하고 관리하는 캘린더입니다.

사용 방법

  • 날짜를 선택합니다.
  • 보강 추가 버튼을 누릅니다.
  • 학생명, 반, 결석 당시 진도, 보강 시간, 메모를 입력합니다.
  • 저장하면 달력과 목록에 반영됩니다.
  • 완료, 취소 등 상태를 변경할 수 있습니다.

입력 방법

학생명, 반, 진도, 메모를 입력한 뒤 저장합니다.

주의사항

달력 날짜를 클릭하면 오른쪽 패널이 갱신됩니다. 날짜 상세 화면은 별도의 상세 버튼으로 확인합니다. 시작 시간을 바꾸면 종료 시간이 자동으로 조정될 수 있습니다.

활용 팁

검색 기능은 학생명뿐 아니라 결석 당시 진도도 함께 찾을 수 있습니다.

Random Picker

Introduction

Randomly pick a student from your class list.

How to use

  • Add student names.
  • Press Pick Random.
  • Optionally exclude already picked students.
  • Use Reset Picks to pick from the full list again.

Input

Type a name and tap Add. While editing, Enter saves and Esc cancels.

Notes

Reset Picks clears pick state only. Use Clear All to remove the entire student list and history.

Team Maker

Introduction

Automatically assign students to teams.

How to use

  • Add student names.
  • Choose by team count or members per team.
  • Press Assign Teams.
  • Press Reassign to shuffle again.

Input

Type a name and tap Add. While editing, Enter saves and Esc cancels.

Notes

At least 2 students are required. If team count exceeds student count, it is adjusted automatically.

Score Board

How to use

Notes

Scores reset on refresh. Keep the tab open during class if you need to preserve the board.

Grammar Checkpoint

WH Factory

Introduction

A drag activity where students sort Who, What, When, Where, Why, and How sentences into the matching boxes.

How to use

  • Enter your sentences.
  • Press Start Game.
  • Drag each card to the correct 5W1H box.
  • Review your score on the results screen.

Input format

Enter one sentence per line (press Enter after each line).

Who: The boy is running. Where: She lives in Seoul. Why: He was late.

Notes

Wrong cards return to the belt. Dropping outside a box does not change your score.

Phonics Hunt

Introduction

A two-team learning game where teams take turns opening word tiles and finding hidden stars.

How to use

  • Enter words and set team names, star count, and star points.
  • Press Start Game to create tiles automatically based on the word count.
  • Each tile shows its word from the start; stars are hidden randomly in the set number of tiles.
  • Press the Blue Team or Red Team turn button, then open the tile matching the word the student says.
  • Opening a star tile adds points to that team.
  • When all tiles are opened, the game ends and scores are compared.

Input format

Enter one word per line (press Enter after each line). At least 2 words are required.

Notes

Star count can be set from 1 up to the number of words entered. Reset Scores clears points only; Edit Words returns to the setup screen.

Barrel Game

Introduction

Pick a hole and stab a sword into the barrel — find which slot makes the pirate pop out.

How to use

  • Set the number of holes and sound options.
  • Press Start Game.
  • Pick a sword or hole number.
  • When the pirate pops out, the round ends.
  • Press Next or Reset to play another round.

Keyboard shortcuts

  • 1–N: select a hole
  • R: reset
  • Esc: back to setup
  • Enter: next round after game over

Notes

The pirate's position is randomized each round.

Pirate Race

Introduction

A race game where two teams move pirate ships toward the goal.

How to use

  • Adjust goal distance, Storm Mode, and Treasure Bonus settings.
  • Select move values +1 through +6 or use Random Move.
  • The first team to reach the goal wins.

Notes

This is not turn-enforced — the teacher manages play order.

Fortress Battle

Introduction

A turn-based classroom battle where Team A and Team B attack each other's fortress HP.

How to use

  • Set starting HP and damage values in Game Settings, then press Apply.
  • Switch turns with Team A Turn / Team B Turn.
  • Choose Attack 1–4 to deal damage based on your configured values.
  • When a fortress reaches 0 HP, the other team wins.
  • Press New Game to restart.

Notes

Damage values are comma-separated numbers (e.g. 0,10,20,30). A value of 0 shows MISS!

Castle Siege

Introduction

A battle activity where two teams attack, repair, and defend castle HP across lesson rounds.

How to use

  • On the setup screen, set team names, castle HP, homework bonus, and lesson rounds.
  • Press Start Battle to enter the battle screen.
  • Use Attack, Repair, Shield, and Charge under each team.
  • Attack reduces the opponent's castle HP; Repair restores your team's HP.
  • Shield builds defense; Charge lets a team act twice on the next turn.
  • When an opponent's castle HP reaches 0, that team wins the round. End Round advances to the next round.
  • After the final round, the lesson is complete.

Homework bonus

  • 50%+ homework completion: choose 1 bonus item
  • 80%+: 1 item + starting Shield +10
  • 100%: choose 2 bonus items
  • Available items: Shield, Repair Kit, Charge

Notes

Attack damage and Shield values are randomized within set ranges. Charge lets the same team act twice in a row.

Treasure Hunt

Introduction

A two-team activity where players dig tiles to collect treasure points.

How to use

  • Select Blue Team or Red Team Excavate to choose the active team.
  • Pick a tile to dig and reveal its contents.
  • Treasures (⭐, 💎, 👑) add points to that team.
  • When all tiles are dug, the game ends and scores are compared.
  • Change grid size with Rows/Cols and press New Map for a fresh board.
  • Reset Game clears scores and starts over.

Special tiles

  • 🗺 Treasure Map: briefly shows one undug treasure location.
  • 💣 Dynamite: the same team picks one more tile.
  • ⛏ Unstable Ground: reshuffles undug tile contents.

Notes

Grid size ranges from 3–8 rows and 3–8 columns. Treasure points: ⭐ 1, 💎 2, 👑 3.

Tug of War

Introduction

A tug-of-war game where the rope moves based on the score difference between two teams.

How to use

  • Set team names and the win point target.
  • Press Start Game.
  • Enter scores for Team A and Team B.
  • Press Pull to move the rope.
  • The first team to reach the win point target wins.

Input

Enter scores as numbers. Press Enter to pull.

Keyboard shortcuts

  • Enter: pull
  • Esc: back to setup

Notes

Scores are entered directly as numbers (0–9), not drawn from cards.

Q. 다른 컴퓨터에서도 같은 데이터를 볼 수 있나요?

A. 현재는 브라우저 localStorage 기반이라 기기마다 데이터가 따로 저장됩니다. 추후 백업/복원 기능을 추가할 예정입니다.

Q. 데이터가 사라질 수 있나요?

A. 브라우저 캐시나 사이트 데이터가 삭제되면 localStorage 데이터가 사라질 수 있습니다. 중요한 데이터는 추후 제공될 내보내기 기능으로 백업하는 것을 권장합니다.

Q. 모바일에서도 사용할 수 있나요?

A. 기본 사용은 가능하지만, 노트북 또는 데스크톱 환경을 권장합니다.

Q. 오류나 건의사항은 어떻게 전달하나요?

A. 교무톡 또는 개발자에게 직접 전달해 주세요.
