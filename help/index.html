공통 안내

한 줄씩 입력하기

학생 이름·문장·단어는 Enter를 눌러 한 줄에 하나씩 입력합니다.

Kevin Emma Sophia

프리셋 저장하기

프리셋은 지금 화면 입력칸에 있는 내용을 이름을 붙여 저장해 두는 기능입니다. (학생 목록, 단어, 항목 등 — 도구마다 다름)

  1. 저장할 내용을 입력칸에 넣습니다.
  2. 프리셋 이름을 적습니다. 반·수업 이름처럼 알아보기 쉬운 이름이 좋습니다.예: DSA1, 3학년 2반
  3. 저장 또는 새로 저장을 누릅니다.

같은 이름으로 다시 저장하면 덮어쓸지 물어볼 수 있습니다.

프리셋 불러오기

  1. 저장된 목록에서 이름을 고릅니다.
  2. 불러오기를 누르면 입력칸 내용이 그때 저장했던 상태로 바뀝니다.

참고

  • 목록을 고친 뒤에는 현재 프리셋 업데이트로 다시 저장할 수 있습니다. (학생 목록 도구)
  • 더 이상 쓰지 않는 프리셋은 선택 후 삭제할 수 있습니다.
  • 저장된 프리셋은 이 컴퓨터·이 브라우저에만 남습니다.
  • Random Picker, Team Maker, Participation Tracker, Vocab Study Tool, Dice Tool 등 일부 도구에서 사용할 수 있습니다.

수업준비 체크리스트

소개

교시별 수업 준비물을 체크하는 도구입니다.

사용 방법

  • ← / → 버튼으로 반 또는 교시를 이동합니다.
  • 필요한 준비물을 체크합니다.
  • 반 설정에서 반 이름을 수정할 수 있습니다.
  • 항목 설정에서 체크리스트 항목을 수정할 수 있습니다.

주의사항

반 설정과 항목 설정은 저장 버튼을 눌러야 반영됩니다. 반마다 체크 항목은 따로 저장됩니다.

오늘 보강 위젯

소개

오늘 예정된 보강 일정을 메인 화면에서 확인하는 위젯입니다.

사용 방법

  • 메인 화면에서 오늘 보강 일정을 확인합니다.
  • ← / → 버튼으로 보강 일정을 넘겨볼 수 있습니다.
  • 일정은 자동으로 전환됩니다.
  • 보강 관리는 Makeup Scheduler에서 진행합니다.

주의사항

위젯에서는 보강을 직접 등록하거나 수정하지 않습니다. 등록과 수정은 반드시 Makeup Scheduler에서 진행합니다.

Classroom Timer

소개

수업 활동 시간을 관리하는 타이머입니다.

사용 방법

  • 숫자를 입력합니다.
  • Start를 눌러 타이머를 시작합니다.
  • Pause로 일시정지할 수 있습니다.
  • Reset으로 초기화할 수 있습니다.

입력 방법

숫자 버튼 또는 키보드 숫자를 사용할 수 있습니다. 예를 들어 630을 입력하면 6분 30초로 설정됩니다.

단축키

  • Enter: 시작 또는 재개
  • Space: 시작, 일시정지, 재개
  • Backspace: 한 자리 삭제
  • C: Clear
  • R: Reset
  • F: 전체화면
  • Esc: 닫기 또는 취소

주의사항

실행 중에는 숫자 입력과 Clear가 비활성화됩니다.

Makeup Scheduler

소개

결석한 학생의 보강 일정을 등록하고 관리하는 캘린더입니다.

사용 방법

  • 날짜를 선택합니다.
  • 보강 추가 버튼을 누릅니다.
  • 학생명, 반, 결석 당시 진도, 보강 시간, 메모를 입력합니다.
  • 저장하면 달력과 목록에 반영됩니다.
  • 완료, 취소 등 상태를 변경할 수 있습니다.

입력 방법

학생명, 반, 진도, 메모를 입력한 뒤 저장합니다.

주의사항

달력 날짜를 클릭하면 오른쪽 패널이 갱신됩니다. 날짜 상세 화면은 별도의 상세 버튼으로 확인합니다. 시작 시간을 바꾸면 종료 시간이 자동으로 조정될 수 있습니다.

활용 팁

검색 기능은 학생명뿐 아니라 결석 당시 진도도 함께 찾을 수 있습니다.

Participation Tracker

소개

학생별 발표와 참여 횟수를 기록하는 도구입니다.

사용 방법

  • 학생 이름을 입력합니다.
  • 수업 시작을 누릅니다.
  • 학생 카드를 터치하면 참여 횟수가 1 증가합니다.
  • 학생 카드를 길게 누르면 참여 횟수가 1 감소합니다.

입력 방법

학생 이름은 Enter를 눌러 한 줄씩 입력합니다.

Kevin Emma Sophia Liam

주의사항

길게 누르기는 약 0.5초 정도 유지해야 작동합니다. 프리셋을 불러올 때 기존 횟수를 유지할지 확인이 나올 수 있습니다.

Class Random Picker

소개

학생을 무작위로 뽑는 도구입니다.

사용 방법

  • 학생 이름을 추가합니다.
  • 랜덤 뽑기 버튼을 누릅니다.
  • 이미 뽑힌 학생을 제외할지 선택할 수 있습니다.
  • 뽑기 초기화로 다시 전체 학생을 대상으로 뽑을 수 있습니다.

입력 방법

학생 이름을 입력한 뒤 추가합니다. 이름 수정 중에는 Enter로 저장하고 Esc로 취소할 수 있습니다.

주의사항

뽑기 초기화는 뽑힌 상태만 초기화합니다. 학생 목록과 뽑기 기록 전체를 지우려면 전체 삭제를 사용합니다.

Team Maker

소개

학생들을 자동으로 팀에 배정하는 도구입니다.

사용 방법

  • 학생 이름을 추가합니다.
  • 팀 수 기준 또는 팀당 인원 기준을 선택합니다.
  • Assign Teams를 누릅니다.
  • 다시 섞고 싶으면 Reassign을 누릅니다.

입력 방법

학생 이름을 입력한 뒤 추가합니다. 이름 수정 중에는 Enter로 저장하고 Esc로 취소할 수 있습니다.

주의사항

최소 2명 이상이 필요합니다. 팀 수가 학생 수보다 많으면 자동으로 조정됩니다.

Score Board

소개

두 팀의 점수와 자원을 관리하는 점수판입니다.

사용 방법

  • 팀 이름과 Bomb Count를 설정합니다.
  • 점수와 Candy, Shield, Stamp를 조정합니다.
  • 메뉴에서 Bomb, Switch Point, Switch Everything을 사용할 수 있습니다.

주의사항

이 도구는 새로고침하면 기록이 사라집니다. 필요한 경우 수업 중 화면을 유지하세요.

Switch Point는 점수만 교환합니다. Switch Everything은 팀의 전체 상태를 교환합니다.

Grammar Checkpoint

소개

문법 문장을 보고 맞는 문장인지 틀린 문장인지 판단하는 활동입니다.

사용 방법

  • Day, Rule, 문항 수를 선택합니다.
  • Start를 누릅니다.
  • 문장을 보고 Approve 또는 Reject를 선택합니다.
  • 필요한 경우 Fix Sentence를 진행합니다.
  • 결과 화면에서 점수를 확인합니다.

주의사항

게임 중에는 Teacher 패널이 숨겨집니다. 오답인 경우 Fix 단계 없이 다음 문항으로 넘어갈 수 있습니다.

Sentence Battle

소개

문장 순서를 맞히며 몬스터와 전투하는 RPG형 문장 배열 게임입니다.

사용 방법

  • 문장을 추가합니다.
  • 몬스터와 보스 HP를 설정합니다.
  • 게임을 시작합니다.
  • 단어 카드를 올바른 순서로 클릭합니다.
  • 보스전에서 아이템을 사용할 수 있습니다.

입력 방법

문장 입력 후 Enter를 누르면 문장이 추가됩니다.

주의사항

[in common]처럼 묶인 표현은 하나의 카드로 처리됩니다. 아이템은 보스전에서만 사용할 수 있습니다.

Sentence Kitchen

소개

재료 카드를 골라 주문서에 맞는 영어 문장을 만드는 활동입니다.

사용 방법

  • 각 재료 입력칸에 단어를 입력합니다.
  • 사용할 주문서 패턴을 선택합니다.
  • 게임을 시작합니다.
  • 재료를 선택해 문장을 만듭니다.
  • 출고 후 다음 주문으로 넘어갑니다.

입력 방법

각 입력칸에는 Enter를 눌러 한 줄씩 입력합니다.

주의사항

선택한 재료를 다시 누르면 선택이 해제됩니다. 출고 후에는 다음 주문 버튼을 눌러야 계속 진행됩니다.

Story Forge

소개

단어 더미에서 단어를 선택해 이야기를 만드는 활동입니다.

사용 방법

  • 사용할 단어를 입력합니다.
  • 라운드 수를 설정합니다.
  • 이야기를 시작합니다.
  • 단어를 클릭해 문장을 만듭니다.
  • 라운드를 반복해 이야기를 완성합니다.

입력 방법

단어는 Enter를 눌러 한 줄씩 입력합니다.

주의사항

단어 더미는 매번 섞입니다. 이미 선택한 단어는 다시 선택할 수 없습니다.

Vocab Study Tool

소개

단어를 3단계로 학습하는 카드형 어휘 활동입니다.

사용 방법

  • 필요한 필드를 선택합니다.
  • 단어와 뜻을 추가합니다.
  • 프리셋을 저장하거나 불러올 수 있습니다.
  • 학습을 시작합니다.
  • 페어 맞추기, 뜻 확인, 스펠링 활동을 진행합니다.

입력 방법

입력란에서 Enter를 누르면 단어가 추가됩니다.

주의사항

타이머를 켜면 시간이 끝났을 때 라운드가 강제로 종료될 수 있습니다.

WH Factory

소개

Who, What, When, Where, Why, How 문장을 분류하는 드래그 활동입니다.

사용 방법

  • 문장을 입력합니다.
  • Start Game을 누릅니다.
  • 카드를 알맞은 5W1H 박스로 드래그합니다.
  • 결과를 확인합니다.

입력 방법

문장은 Enter를 눌러 한 줄씩 입력합니다.

Who: The boy is running. Where: She lives in Seoul. Why: He was late.

주의사항

오답 카드는 다시 원래 위치로 돌아갑니다. 박스 밖에 놓으면 점수 변화가 없습니다.

Barrel Game

소개

구멍을 선택해 칼을 꽂고, 통아저씨가 튀어나오는 칸을 찾는 게임입니다.

사용 방법

  • 구멍 수와 효과음을 설정합니다.
  • 게임을 시작합니다.
  • 칼 또는 구멍을 선택합니다.
  • 통아저씨가 나오면 라운드가 종료됩니다.
  • Next 또는 다시 시작으로 다음 라운드를 진행합니다.

단축키

  • 숫자 1–N: 구멍 선택
  • R: 다시 시작
  • Esc: 취소
  • Enter: 게임 종료 후 다음 진행

주의사항

메뉴에는 Barrel Game으로 표시되지만, 실제 화면 제목은 통아저씨 게임입니다.

Cannon Game

소개

두 팀이 요새 HP를 깎으며 대결하는 전투형 게임입니다.

사용 방법

  • HP와 데미지 설정을 적용합니다.
  • 공격할 팀 또는 턴을 선택합니다.
  • Attack 버튼을 눌러 공격합니다.
  • 상대 요새 HP가 먼저 0이 되면 승리합니다.

주의사항

Attack 버튼의 숫자는 고정 데미지를 의미하지 않을 수 있습니다. 실제 데미지는 설정된 옵션 안에서 무작위로 적용됩니다.

Dice Tool

소개

주사위 결과에 따라 숨겨진 보상이나 미션을 공개하는 도구입니다.

사용 방법

  • 최소 6개의 보상 또는 미션을 입력합니다.
  • Start를 누릅니다.
  • 결과 행을 클릭해 내용을 공개합니다.
  • Reset Round로 새 라운드를 시작합니다.

입력 방법

보상 또는 미션은 Enter를 눌러 한 줄씩 입력합니다.

단축키

  • Esc: 닫기
  • R: 리셋
  • F: 전체화면
  • Enter/Space: 선택 항목 공개

주의사항

최소 6개 항목이 필요합니다.

Ladder Game

소개

사다리타기로 순서나 결과를 정하는 도구입니다.

사용 방법

  • 결과 항목을 입력합니다.
  • 게임을 시작합니다.
  • 가림막을 클릭합니다.
  • 번호를 선택해 결과를 확인합니다.

입력 방법

결과 항목은 Enter를 눌러 한 줄씩 입력합니다.

단축키

  • R: 사다리 보드 다시 만들기

주의사항

참가자 수는 결과 항목 수에 따라 자동으로 정해집니다.

Mystery Box

소개

여러 항목을 박스에 숨기고 하나씩 공개하는 추첨 도구입니다.

사용 방법

  • 항목을 입력합니다.
  • 게임을 시작합니다.
  • 박스를 클릭해 숨겨진 내용을 확인합니다.
  • 다시 섞기로 새 라운드를 진행할 수 있습니다.

입력 방법

항목은 Enter를 눌러 한 줄씩 입력합니다.

단축키

  • Esc: 닫기
  • R: 리셋
  • F: 전체화면
  • Enter/Space: 선택 항목 공개

주의사항

새 라운드마다 다시 섞기 옵션을 끄면 Reset 후에도 배치 순서가 유지됩니다.

Nerf Gun Roulette

소개

여러 보드 이미지 중 하나를 무작위로 뽑는 슬롯형 활동 도구입니다.

사용 방법

  • 뽑기 버튼을 누릅니다.
  • 슬롯 애니메이션이 진행됩니다.
  • 결과 보드가 자동으로 표시됩니다.
  • 뒤로 가기로 다시 뽑기 화면으로 돌아갑니다.

주의사항

보드 목록은 고정되어 있으며, 화면에서 직접 항목을 수정하는 기능은 없습니다.

Pirate Race

소개

두 팀이 해적선을 움직여 목표 지점에 먼저 도착하는 레이스 게임입니다.

사용 방법

  • 목표 거리, Storm, Treasure 설정을 조정합니다.
  • +1부터 +6까지 이동 값을 선택하거나 Random Move를 사용합니다.
  • 먼저 목표 지점에 도착한 팀이 승리합니다.

주의사항

턴제 게임이 아니므로 교사가 진행 순서를 직접 관리해야 합니다.

Tug of War

소개

두 팀의 점수 차이에 따라 줄이 움직이는 줄다리기 게임입니다.

사용 방법

  • 팀 이름과 승리 포인트를 설정합니다.
  • 게임을 시작합니다.
  • A팀과 B팀의 점수를 입력합니다.
  • 당기기 버튼을 눌러 줄을 이동시킵니다.
  • 승리 포인트에 먼저 도달한 팀이 승리합니다.

입력 방법

점수는 숫자로 직접 입력합니다. Enter를 누르면 당기기가 실행됩니다.

단축키

  • Enter: 당기기
  • Esc: 설정 열기 또는 닫기

주의사항

화면 문구에 카드 표현이 있을 수 있지만, 현재 코드 기준으로는 카드를 뽑는 기능이 아니라 숫자를 직접 입력하는 방식입니다.

Q. 다른 컴퓨터에서도 같은 데이터를 볼 수 있나요?

A. 현재는 브라우저 localStorage 기반이라 기기마다 데이터가 따로 저장됩니다. 추후 백업/복원 기능을 추가할 예정입니다.

Q. 데이터가 사라질 수 있나요?

A. 브라우저 캐시나 사이트 데이터가 삭제되면 localStorage 데이터가 사라질 수 있습니다. 중요한 데이터는 추후 제공될 내보내기 기능으로 백업하는 것을 권장합니다.

Q. 모바일에서도 사용할 수 있나요?

A. 기본 사용은 가능하지만, 노트북 또는 데스크톱 환경을 권장합니다.

Q. 오류나 건의사항은 어떻게 전달하나요?

A. 교무톡 또는 개발자에게 직접 전달해 주세요.
